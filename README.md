# AI 即興作曲 DJ（v5）

一個在瀏覽器中執行的即時音樂 App：從麥克風聽到的聲音擷取靈感音，寫成完整的流行歌，再由雙唱盤 AI DJ 不間斷地接歌。

## 功能

- **麥克風靈感音**：隨意哼歌、彈奏、敲杯子或環境聲都可以，App 會從中擷取 3–5 個「靈感音」（Seed）。
- **自動作曲**：以靈感音作為副歌 Hook（主歌沿用它的音型輪廓），發展成「前奏 → 主歌 → 導歌 → 副歌 →（主歌 → 導歌 → 副歌）→ 橋段 → 最後副歌 → 尾奏」的完整流行歌（約 80–170 秒），配上七和弦、九和弦、掛留與轉位等和聲及分層編曲。
- **六種曲風**：R&B 流行、民謠敘事、力量情歌、抒情鋼琴、美式流行、韓式流行；依麥克風聽到的強度、亮度與節奏密度自動選擇。所有旋律皆為即時生成，不使用任何既有歌曲。
- **雙唱盤 DJ**：下一首歌會在背景預先寫好；預設在舊歌最後四小節交叉混音，另有濾波器掃頻、等化器交換、升頻噪音、回聲甩尾、反向鈸聲、鼓組橋接、瞬間 Drop 等手法，並平滑調整速度、挑選相近的調。
- **取樣樂器**：鋼琴、吉他、貝斯、弦樂與鼓組皆使用 FluidR3_GM 音色庫取樣（MIT 授權），詳見 `samples/LICENSE.txt`；合成器鋪底為即時合成。

## v5 更新重點

### 混音
- 共用效果 bus（兩個 Deck 共用，不為每個音符建立殘響）：主旋律與小鼓送 plate 殘響（約 1.4 秒，送出量 18–25%）、鋪底與弦樂送 hall 殘響（約 2.4 秒，送出量 40–50%）；兩者都有 25 ms 預延遲，回送路徑 HP 250 Hz／LP 8 kHz。貝斯與大鼓不加殘響；副歌主旋律 plate 提高到 30%，另送 hall 10%。
- 主旋律附點八分乒乓延遲（回授 0.32、回授路徑 LP 3.5 kHz）；鋼琴、鋪底與琶音的立體聲合唱。
- 側鏈閃避：每個大鼓先回到 1，5 ms 內壓到設定深度，20 ms 後以 0.12 拍為時間常數回復；鋪底、鋼琴和弦、弦樂與吉他壓到 0.5，貝斯有自己的側鏈（0.6）；抒情類曲風只在副歌閃避，深度 0.8。
- 立體聲寬度：刷弦吉他雙軌左右 ±0.7（第二軌晚 15 ms）、弦樂聲像 -0.7／-0.25／+0.25／+0.7、鋼琴依音高 ±0.35、琶音左右交替 ±0.5；主旋律、大鼓、小鼓與貝斯置中，150 Hz 以下維持單聲道。
- 美式流行與韓式流行：約一半的歌在副歌改用合成主旋律（兩個鋸齒波 ±7 cents＋高八度方波 -12 dB、LP 3.5 kHz、ADSR 8 ms／200 ms／0.7／250 ms、0.3 秒後 5.5 Hz ±15 cents 顫音），並在貝斯下加正弦 sub bass（LP 120 Hz、-6 dB）。
- 主控：HP 30 Hz → 低頻／高頻擱架 → 動態低通（14–18 kHz）→ 壓縮（-14 dB、2:1、30／150 ms、knee 6）→ 軟削波 → 限幅（-1 dB、20:1、1／50 ms）→ 主音量（最大 0.9）。各樂器位準以大鼓為 0 dB 校正（小鼓 -3、貝斯 -3、主旋律 -4、鋼琴 -8、吉他 -10、弦樂 -12、鋪底 -14 dB）。

### 動態
- 段落力度：主歌 0.4、導歌 0.6、副歌 0.95，最後副歌再加 0.12；音量 = 0.3 + 0.7 × 力度。
- 第一段主歌只用 2–3 層樂器；導歌最後一小節後半鼓與貝斯停下，只留上升音效、主旋律或小鼓滾奏；副歌第一拍加上鈸與重低音。

### 旋律
- 速度：一般 88–118 BPM、抒情曲 72–84 BPM；大調約 70%、小調約 30%。
- 副歌 8 小節 A A B A'：第一句是鎖定的 Hook，第二句只改最後一音，第三句把 Hook 模進（上移 2 或 4 度），第四句回到 Hook 並結束在主音；Hook 很短（≤ 8 個十六分音符）時在一句內重複兩次。
- 美式流行、韓式流行與 R&B 流行約一半的歌，副歌第一音會提前半拍搶進（伴奏和弦同時提前）。
- 副歌與導歌的強拍約 15–25% 為倚音（9 度或 4 度，下一音級進解決），其餘為和弦音；同音重複機率依曲風（美式 .35、韓式 .4、力量情歌 .2、抒情 .25）；搖擺感 R&B .18、抒情 .06。
- 主歌 A A' B A''、導歌上行且結束在屬音、橋段改變方向並停在屬和弦；樂句最高音落在第 1 或第 3 拍，同音最多連續三次；第二次副歌完全相同，最後副歌升調或加倍。

### 和聲與編曲
- 和弦表：前奏 I–V–vi–IV、主歌 vi–IV–I–V 或 I–iii–IV–V、導歌 IV–V–vi–V（停在 V）、副歌 I–V–vi–IV（第二輪最後一小節 IV → V），美式流行另有 ♭VII–IV–I 與 IV–I–V–vi、韓式流行小調另有 i–♭VII–♭VI–v；副歌句子重複時若長音與和弦成小二度，自動換成含該音的調內和弦；副歌句尾唱主音而和弦在 V 時用 V7sus4。
- 分層：前奏鋼琴琶音＋鋪底＋輕 Hi-hat；主歌加入貝斯與大鼓；導歌加入弦樂、十六分音符 Hi-hat 與小鼓滾奏；副歌全編制、主旋律高八度疊加；橋段精簡，最後一小節加上升濾波；每段結尾留 1/8 拍呼吸。

## 使用方式

1. 麥克風需要安全環境：請透過 **https** 或 **http://localhost** 開啟（直接以 `file://` 開啟無法使用麥克風）。
   例如在此資料夾執行：`python3 -m http.server 8000`，再開啟 <http://localhost:8000/>。
2. 按下「開始」並允許使用麥克風；也可以使用示範模式，不需麥克風。
3. **建議戴耳機**，避免喇叭播放的音樂被麥克風收回去，影響靈感音擷取。
