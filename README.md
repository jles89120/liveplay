# AI 即興作曲 DJ（v4）

一個在瀏覽器中執行的即時音樂 App：從麥克風聽到的聲音擷取靈感音，寫成完整的流行歌，再由雙唱盤 AI DJ 不間斷地接歌。

## v4 功能

- **麥克風靈感音**：隨意哼歌、彈奏、敲杯子或環境聲都可以，App 會從中擷取 3–5 個「靈感音」（Seed）。
- **自動作曲**：以靈感音作為副歌與主歌的 Hook，透過模進、倒影、節奏變化與呼應句，發展成「前奏 → 主歌 → 導歌 → 副歌 → 橋段 → 最後副歌 → 尾奏」的完整流行歌（約 60–90 秒），並配上七和弦、九和弦、掛留與轉位等豐富和聲及分層編曲。
- **六種曲風**：R&B 流行、民謠敘事、力量情歌、抒情鋼琴、美式流行、韓式流行；依麥克風聽到的強度、亮度與節奏密度自動選擇。所有旋律皆為即時生成，不使用任何既有歌曲。
- **雙唱盤 DJ**：下一首歌會在背景預先寫好，DJ 在樂句邊界以濾波器掃頻、等化器交換、升頻噪音、回聲甩尾、反向鈸聲、鼓組橋接或瞬間 Drop 等手法接歌，並平滑調整速度、挑選相近的調。
- **取樣樂器**：鋼琴、吉他、貝斯、弦樂與鼓組皆使用 FluidR3_GM 音色庫取樣（MIT 授權），詳見 `samples/LICENSE.txt`。

## 使用方式

1. 麥克風需要安全環境：請透過 **https** 或 **http://localhost** 開啟（直接以 `file://` 開啟無法使用麥克風）。
   例如在此資料夾執行：`python3 -m http.server 8000`，再開啟 <http://localhost:8000/>。
2. 按下「開始」並允許使用麥克風；也可以使用示範模式，不需麥克風。
3. **建議戴耳機**，避免喇叭播放的音樂被麥克風收回去，影響靈感音擷取。
